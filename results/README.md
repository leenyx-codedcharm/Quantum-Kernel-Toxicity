# Results Directory

This directory stores experiment outputs, derived tables, figures, and reports.

## Organisation

- `reports/`: curated research tables, plots, progress reports, and manuscript-facing summaries.
- `quantum_benchmarks/`: quantum and hybrid experiment outputs, including configurations and manifests.
- `visualizations/`: generated scientific figures.

## Provenance

Every reported result should be traceable to:
- an experiment configuration,
- frozen molecule IDs and split definitions,
- saved predictions,
- a model-selection record,
- an experiment manifest.

Exploratory single-split results must be labelled as such. Do not combine them with five-scaffold averages as though they were measured under the same evaluation design.
